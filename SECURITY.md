# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest `main` | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public GitHub issue
2. **Email** [jmk9494@gmail.com](mailto:jmk9494@gmail.com) with:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
3. You will receive a response within **72 hours**

## Scope

This project processes API calls to third-party LLM providers. Security concerns include:

- API key exposure in logs or responses
- Injection attacks through prompt data
- Unauthorized access to audit data
- Cross-site scripting (XSS) in the dashboard

Thank you for helping keep Moderation Bias secure.
