# Moderation Bias — Web Frontend

The Next.js (App Router) frontend for [moderationbias.com](https://moderationbias.com),
an open-source benchmark tracking censorship and content-moderation bias across 30+ LLMs.

It renders the pre-computed audit data (JSON/CSV produced by the Python pipeline in
the repository root) into interactive comparisons, analysis dashboards, and charts,
and hosts the human-annotation and grading APIs backed by Vercel Blob storage.

## Running locally

```bash
cd web
npm install
npm run dev
# → http://localhost:3000
```

`npm run dev` first runs `scripts/prepare-data.js`, which downloads the gzipped audit
CSVs from Vercel Blob into `public/` if they are missing (they are gitignored and
regenerated by the audit pipeline).

## Scripts

| Script              | Purpose                                            |
| ------------------- | -------------------------------------------------- |
| `npm run dev`       | Start the dev server (Webpack; next-pwa disabled)  |
| `npm run build`     | Production build                                   |
| `npm run start`     | Serve the production build                         |
| `npm run lint`      | ESLint                                             |
| `npm run typecheck` | `tsc --noEmit`                                     |
| `npm test`          | Vitest unit tests                                  |
| `npm run test:e2e`  | Playwright end-to-end tests                        |

## Layout

- `app/` — App Router routes (compare, analysis/*, models, categories, annotate, api/*)
- `components/` — shared React components and charts
- `lib/` — data loading, chart theme, formatters, utilities
- `public/` — pre-computed JSON data assets and static images

See the [root README](../README.md) for the full project (Python audit pipeline,
methodology, and data documentation).
